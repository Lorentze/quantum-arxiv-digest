# SciRate 来源与晚间分析

源页面：[quant-ph 三日榜单](https://scirate.com/arxiv/quant-ph?range=3)。只收集当前票数严格大于 10 的文章。按照 SciRate 官方实现，三日窗口以 feed 的最新公告日为终点；票数是文章当前累计 scites 数。

```bash
qradar collect --source scirate --profile config/profile.json --state data/state.json --output public --site-url https://lorentze.github.io/quantum-arxiv-digest/
```

公开页面遭 403 / Cloudflare challenge 时明确失败，不尝试绕过，也不将其记成成功空榜。未发表候选和已有报告保留。GitHub Actions 使用北京时间 19:00 对应的 UTC 11:00 cron；ChatGPT 晚间任务按 Asia/Shanghai 精确日程启动，等待收集并阅读官方 arXiv 来源，完成后才发表报告。
