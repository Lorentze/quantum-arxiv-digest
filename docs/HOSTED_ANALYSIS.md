# Hosted 分析：arXiv 与正式期刊

默认不需要 API key。GitHub Actions 每天北京时间 08:17 收集 arXiv 与已启用期刊；ChatGPT 每天北京时间 09:00 启动分析，完成后写回并发布。SciRate 和 19:00 的更新已取消。

首页和 RSS 保留英文原标题、原始摘要、明确来源及原文链接；主链接进入站内中文技术报告。正式发表论文增加 publication_significance，解释为何适合对应期刊，这是阅读判断，不是编辑决定记录。

期刊来源和日期规则见 [JOURNAL_SOURCES.md](JOURNAL_SOURCES.md)。新论文进入 pending；已分析预印本的正式发表记录合并到原条目，通过独立 publication_reviews_pending 队列补充发表价值分析。两者由同一 importer 校验后发布，已存在报告不会因补充分析消失。
